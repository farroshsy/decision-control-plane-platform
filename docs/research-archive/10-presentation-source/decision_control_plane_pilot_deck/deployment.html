03 / Deployment sequence

Ten deployment steps

The exact path from pilot charter to canary cutover and closeout. Each step has an exit condition; the next step does not begin just because the calendar says so.
01
Approve charter
Define scope, owners, RPO/RTO targets, and success gates.
02
Landing zone
Establish tenant isolation, KMS keys, identities, and network policies.
03
Register contracts
Publish schemas, policies, and state manifests. Enable compatibility checks.
04
Connect adapter
Validate ingress, canonicalization, and provenance without action execution.
05
Capture incumbent
Build the historical replay and comparison corpus from legacy decisions.
06
Shadow mode
Run Policy Interpreter, compare outputs, and classify all divergence.
07
Validate resilience
Execute RPO admission, partition fencing, and tenant isolation drills.
08
Action dry run
Test idempotency and reconciliation on a safe, non-executing endpoint.
09
Canary cutover
Advance ownership epoch for a bounded cohort and monitor telemetry.
10
Pilot closeout
Produce evidence package, measure economics, and decide on expansion.
