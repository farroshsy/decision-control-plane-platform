02 / Proving ground

The first wedge is financial-crime screening

It forces the system to be precise where failure is expensive.One transaction can test the whole theory: identity, relationships, evidence, policy, action, audit, and change over time.
Identity
Aliases, transliteration, mononyms, beneficial owners
Time
Event time, processing time, late updates
Policy
Effective dates, unknowns, hard constraints
Action
Allow, hold, block, review, reconcile
Audit
Trace, evidence, versions, replay
Resilience
Burst load, stale state, dependency failure
Falsifier: if the kernel cannot survive this wedge without semantic exceptions, it is not a reusable infrastructure category.
