08 / Validation Metrics

Success is measured in proof, not activity

Decision Replay
≥99.99% of pinned decisions reproduce exactly
Any unexplained divergence on a material decision
Audit Completeness
100% of acknowledged actions have a recoverable trace
Any acknowledged action without durable trace
Hot-Path Latency
Policy Interpreter p99 ≤10 ms; full disposition p99 ≤100 ms
Sustained breach for 5 minutes at nominal load
Resilience
100% of injected critical failures produce explicit degraded behavior
Any silent allow caused by dependency failure
Operational Value
Median analyst reconstruction time improves by ≥50%
No measurable improvement or worse accuracy
Adapter Isolation
AML-specific code is confined to adapter boundaries
Kernel changes required for ordinary AML semantics
