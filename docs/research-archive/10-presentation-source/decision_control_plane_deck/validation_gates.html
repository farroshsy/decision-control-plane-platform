07 / Validation Plan

The 90-day MVP validation plan

G0
Contract freeze
Days 1–14
Are schemas, policy semantics, failure modes, and falsifiers explicit?
Exit: Proceed only if an independent reviewer can implement and challenge the contracts.
G1
Deterministic kernel
Days 15–35
Can the same decision be reconstructed after restart, duplicates, late events, and version changes?
Exit: Proceed only if replay and audit invariants pass.
G2
AML vertical slice
Days 36–60
Can one transaction flow from adapter to policy to action to audit?
Exit: Proceed only if hold, allow, unknown, and action ambiguity paths pass.
G3
Production-like validation
Days 61–80
Does the system meet latency, throughput, resilience, and operational targets?
Exit: Proceed only if no critical failure mode is unresolved.
G4
Generalization decision
Days 81–90
Is the kernel reusable, or is this only an AML implementation?
Exit: Add a second adapter, narrow the thesis, or stop.
Outcome Proceed, narrow, or stop based on hard evidence, not momentum.
